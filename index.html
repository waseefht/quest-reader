🎬 الدبلجة — قارئ الترجمة بصوت نسائي

عذرًا، هذا المتصفح لا يدعم تحويل النص إلى كلام (speechSynthesis). جرّب تحديث متصفح Quest أو متصفحًا آخر.

🚀 ابدأ

🎬 ثبّت إضافة «الدبلجة» (ضغطة واحدة) 🥽 مشغّل فيديو VR🎬 تجربة

ثبّت الإضافة مرة واحدة، ثم على أي موقع فيلم: ضغطة = دبلجة مخفية، ضغطتان سريعتان = الصندوق. احفظ الإعدادات أدناه قبل نسخ الإضافة لتُضمَّن فيها.

⚙️ الإعدادات

🌐 لا توجد أصوات مدمجة في هذا المتصفح — يُستخدم صوت نسائي عبر الإنترنت.

المفتاح يُحفظ في هذا المتصفح فقط ويُرسَل صوت الفيديو إلى OpenAI. التفريغ مدفوع بالدقيقة — راجع أسعار OpenAI الحالية. بدون مفتاح: يُستخدم الميكروفون (مجاني، جودة أقل) إن دعمه المتصفح. الفيديو المحمي (DRM) أو من مصدر خارجي لا يمكن التقاط صوته.

ℹ️ كيف يعمل «الدمج»؟ ولماذا صوت الإنترنت؟أثناء كل جملة يُخفَض صوت الفيديو تدريجيًا (150ms) ثم يعود، وتُضبط سرعة الكلام (0.9–1.6) لينتهي مع نهاية الجملة المترجمة. المؤثرات المتقدمة (صدى غرفة، موازنة، ضاغط، توجيه حسب مكان الفيديو، وخفض ترددات الأصوات الأصلية بدل خفض الصوت كله) تعمل فقط حين يسمح المتصفح بتمرير الصوت عبر Web Audio: عند الفتح عبر الـ Worker أو في مشغّل VR مع Worker. على المواقع العادية: خفض الصوت فقط. متصفح Quest غالبًا بلا أصوات مدمجة، لذا يُستخدم صوت نسائي عبر الإنترنت (Google، يرسل النص إليها). لا يتم استنساخ صوت الممثل.

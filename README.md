# 🔊 QuestReader — قارئ النصوص والترجمات لمتصفح Meta Quest

تطبيق ويب (PWA) قابل للتثبيت، **للقراءة الصوتية فقط** (تحويل النص إلى كلام) — بدون ترجمة صوتية. مكتوب بـ HTML/CSS/JS عادي بدون أي خطوة بناء.

## المكوّنات
| الملف | الوظيفة |
|---|---|
| `index.html` + `app.js` | الصفحة الرئيسية: قراءة نص ملصوق أو ملف txt، القراءة بالإشارة (فقاعة)، فتح موقع عبر الـ Worker |
| `overlay.js` / `bookmarklet.js` | صندوق قارئ الترجمة (قابل للسحب وتغيير الحجم) — النسخة الكاملة والمصغّرة |
| `install.html` | صفحة الإضافات (Bookmarklets) مع أزرار نسخ |
| `test.html` + `sample.webm` + `sample.vtt` | صفحة تجربة قارئ الترجمة |
| `vr/` | مشغّل فيديو VR (WebXR + three.js محلي) مع ترجمة مقروءة |
| `proxy/` | Cloudflare Worker لفتح أي موقع مع تشغيل القارئ تلقائيًا |
| `handoff.js` / `handoff-bookmarklet.js` | Bookmarklet «افتح في VR» من Chrome/Edge إلى Quest Browser (`node test-handoff.js` للاختبار) |
| `hidden-bookmarklet.js` | نسخة القارئ المخفي (مولّدة) |
| `build.mjs` | يعيد توليد bookmarklet.js و install.html و proxy/worker-single.js بعد تعديل overlay.js (`node build.mjs`) |

## 1) الاستضافة (HTTPS ضروري للتثبيت)
**Netlify Drop (الأسهل):** افتح https://app.netlify.com/drop واسحب مجلد `QuestReader` كاملًا ← تحصل على رابط https.
**GitHub Pages:** أنشئ مستودعًا وارفع محتويات المجلد ← Settings ← Pages ← Branch: main / root ← الرابط `https://USER.github.io/REPO/`.

## 2) التثبيت على Meta Quest Browser
1. افتح الرابط في متصفح Quest.
2. افتح القائمة (⋮) ← **Install / تثبيت التطبيق** أو **Add to apps** (قد تظهر أيقونة تثبيت في شريط العنوان).
3. يظهر التطبيق في مكتبة التطبيقات ويعمل دون إنترنت (Service Worker).

## 3) قراءة النص
الصق النص ← «عرض للقراءة بالإشارة». أشِر بشعاع اليد/المتحكم إلى جملة 600ms أو انقر عليها ← تظهر فقاعة وتُقرأ تلك الجملة فقط. تحديد نص يظهر الفقاعة لقراءة التحديد. «قراءة الكل» يقرأ جملة جملة مع تظليل الجملة الحالية. السرعة وطبقة الصوت والنص تُحفظ تلقائيًا.

## 4) قارئ الترجمة (صندوق)
صندوق شفاف بحواف قابلة للسحب: اسحبه من الشريط (✥) وكبّره من الزوايا والحواف، وضعه فوق مكان الترجمة. الأزرار: 🔊 تشغيل/إيقاف، اختيار الصوت، السرعة، ⚡مقاطعة/⏭️طابور، 🎯 تقييد بالمنطقة، 🔍 OCR، ▁ تصغير، ✕ إغلاق. الحجم والمكان يُحفظان (لكل موقع).
- **يعمل مع:** مسارات الترجمة النصية في `<video>` (VTT)، **YouTube** (فعّل CC)، والمواقع التي تعرض الترجمة كنص في الصفحة. يبقى ظاهرًا في وضع ملء الشاشة.
- **OCR (للترجمة المحروقة في الصورة):** يحمّل Tesseract.js (ara+eng) من CDN عند الطلب ويقرأ منطقة الصندوق كل ~700ms. يحتاج إنترنت، وبطيء نسبيًا على Quest.
- **Netflix/المحتوى المحمي (DRM):** OCR مستحيل (الصورة محمية) وتظهر رسالة واضحة؛ قد تعمل ترجمة Netflix النصية (`.player-timedtext`) لكن ذلك غير مضمون.

## 4ب) القارئ المخفي «🔈 قارئ مخفي»
إشارة منفصلة في `install.html` (ونسخة «بدون إشعار»). ضغطة واحدة تبدأ القراءة تلقائيًا **بدون أي صندوق أو أزرار على الشاشة**:
- يلتقط مسارات الترجمة في الفيديو (ويفعّلها بشكل مخفي إن كانت معطّلة) وترجمات الصفحة النصية في أي مكان (YouTube، ‎.player-timedtext، عناصر caption/subtitle).
- يختار صوتًا أنثويًا باللغة المكتشفة تلقائيًا، ويستخدم السرعة/الصوت المحفوظين من وضع الصندوق.
- التأكيد: يقول «تم التشغيل» مع إشعار صغير يختفي خلال 1.5 ثانية (النسخة «بدون إشعار» تكتفي بالصوت).
- اضغط الإشارة نفسها مرة أخرى للإيقاف ← «تم الإيقاف». يستمر في وضع ملء الشاشة.
- لا يوجد OCR في الوضع المخفي (استخدم وضع الصندوق لذلك).

## 5) إضافة Bookmarklet في Quest Browser
1. افتح `install.html` واضغط «📋 نسخ الكود» للإضافة المطلوبة.
2. في أي صفحة: القائمة ← **Add bookmark / إضافة إشارة**.
3. افتح **Bookmarks** ← ⋮ بجانب الإشارة ← **Edit / تعديل**.
4. غيّر الاسم، **احذف الرابط والصق الكود** (يبدأ بـ `javascript:`) ← احفظ.
5. افتح موقع الفيلم، ثم اختر الإشارة من قائمة الإشارات لتشغيلها على الصفحة.

الإضافات المتاحة:
- **🔊 قارئ الترجمة** (~17KB؛ إن رفض المتصفح الحفظ لطوله استخدم الـ Worker).
- **🌐 ترجمة الصفحة (Proxy):** ينقل الصفحة إلى نسخة Google المترجمة `*.translate.goog` (تبقى الروابط مترجمة أثناء التصفح)، يسأل عن اللغة (الافتراضي ar)، ولا يكرر التغليف إذا كنت أصلًا على translate.goog.
- **🌐 ترجمة داخل الصفحة:** يحقن مترجم Google في الصفحة للمواقع التي تفشل مع الـ Proxy (تسجيل دخول/ديناميكية). قد تمنعه سياسة CSP.
> ملاحظة: «ترجمة الصفحة» هي ترجمة نص الموقع المرئي فقط؛ القارئ الصوتي نفسه لا يترجم.

## 6) فتح أي موقع مع القارئ تلقائيًا (Cloudflare Worker)
بعد النشر تكتب: `https://اسمك.workers.dev/https://site.com` فيعمل القارئ تلقائيًا في كل صفحات الموقع (يقرأ مسارات الترجمة وترجمات DOM دون الحاجة لوضع الصندوق؛ زر 🎯 لتقييد القراءة بمنطقة الصندوق).
الوضع الافتراضي عبر الـ Worker هو **القارئ المخفي**. لإظهار الصندوق أضف `?ui=box` (أو `&ui=box`) إلى رابط الموقع مرة واحدة، ويُحفظ في كوكي؛ و `ui=hidden` للعودة. (يُحذف معامل `ui` من الرابط قبل إرساله للموقع.)

**النشر من لوحة التحكم (بدون CLI):**
1. أنشئ حسابًا مجانيًا على https://dash.cloudflare.com.
2. Workers & Pages ← Create ← Create Worker ← سمّه ← Deploy.
3. Edit code ← احذف الموجود والصق محتوى **`proxy/worker-single.js`** كاملًا ← Deploy.
4. ضع رابط الـ Worker في خانة الصفحة الرئيسية للتطبيق، والصق رابط الموقع ← «فتح عبر القارئ».

**أو عبر wrangler:** `cd proxy && npx wrangler login && npx wrangler deploy` (يستخدم `worker.js` + `rewrite.js` + `reader.txt`؛ شغّل `node build.mjs` أولًا لتحديث reader.txt).

ما يفعله: يحقن `/__reader.js` في `<head>`، يعيد كتابة الروابط (a/form/src/srcset/iframe…) لتمر عبر الـ Worker، يحذف CSP و X-Frame-Options، يعيد كتابة `Location` في التحويلات وروابط ملفات m3u8/vtt، يمرر الفيديو كتدفق، ويمرر الكوكيز بشكل أدنى.
**حدود صريحة:** مواقع DRM (Netflix, Disney+…) ومواقع تسجيل الدخول المعقدة وحماية البوتات (Cloudflare challenge, captcha) غالبًا ستتعطل؛ طلبات JavaScript المطلقة إلى نطاقات أخرى لا تُعاد كتابتها؛ الحصة المجانية 100 ألف طلب يوميًا. **للاستخدام الشخصي فقط** واحترم شروط المواقع. لا تسجّل الدخول بحسابات مهمة عبر الـ Proxy.

## 7) مشغّل فيديو VR (`vr/index.html`)
افتح ملف فيديو من الجهاز أو الصق رابطًا ← اختر الصيغة (مسطح 2D، 360/180 أحادي، 360/180 ستيريو SBS أو TB) ← «دخول VR».
- التحكم: الزناد = تشغيل/إيقاف أو الضغط على أزرار اللوحة، العصا يمين/يسار = ±10 ثوانٍ، زر A/X أو القبضة = إظهار/إخفاء اللوحة. اللوحة فيها تشغيل، شريط تقدم، تبديل الصيغة، إعادة التوسيط.
- الترجمة: حمّل `.vtt` أو `.srt` (يُحوَّل تلقائيًا) ← تظهر على لوحة داخل VR وتُقرأ بصوت (يفضّل صوتًا أنثويًا باللغة المكتشفة).
- روابط الفيديو تحتاج أن يسمح الخادم بـ **CORS**؛ وإلا حمّل الملف محليًا. WebXR الغامر متاح في Meta Quest Browser (وليس في نسخ Chrome/Edge على Quest).

## 8) التحويل من Chrome/Edge إلى Meta Quest Browser («🥽 افتح في VR»)
WebXR الغامر لا يعمل في Chrome/Edge المثبّتين جانبيًا على Quest، لذا يوجد Bookmarklet «افتح في VR» في `install.html`:
1. أضفه كإشارة مرجعية في Chrome/Edge (نفس خطوات القسم 5).
2. في صفحة الفيديو شغّله: يبحث عن الفيديو (المشغّل حاليًا/الأكبر ← `source` ← `og:video` ← رابط الصفحة كبديل أخير)، ويخمّن الصيغة (180/360/SBS/TB) من اسم الملف والعنوان، ويضيف زر «🥽 افتح في VR» فوق كل فيديو.
3. أول مرة يسأل عن رابط مشغّل VR المستضاف (https) ويحفظه في localStorage.
4. ينتقل إلى رابط Android intent:
`intent://HOST/PATH/vr/index.html?src=...&fmt=...#Intent;scheme=https;package=com.oculus.browser;S.browser_fallback_url=...;end`
فيفتح Meta Quest Browser على المشغّل، والذي يقرأ `?src=&fmt=&sub=` ويحمّل الفيديو تلقائيًا ويعرض زرًا كبيرًا «دخول VR» (WebXR يتطلب ضغطة من المستخدم).

**ملاحظات صريحة:**
- **لم يُجرَّب على جهاز Quest حقيقي.** قد يتجاهل نظام Quest أو المتصفح الـ intent.
- إذا فشل فتح Quest Browser، يفتح `browser_fallback_url` المشغّلَ **في نفس المتصفح (Chrome/Edge)**: يعمل كمعاينة ثنائية الأبعاد فقط دون VR. يمكنك حينها نسخ الرابط وفتحه يدويًا في Quest Browser.
- عند التشغيل داخل Quest Browser نفسه ينتقل مباشرة إلى رابط https بدل intent.
- **يمكن نقل روابط الملفات المباشرة فقط (mp4/webm/m3u8).** تدفّقات `blob:`/MSE (YouTube وأغلب المنصات) وDRM (Netflix…) لا يمكن نقلها؛ عندها يُرسل رابط الصفحة فقط ولن يعمل كفيديو.
- يجب أن يسمح خادم الفيديو بـ CORS وأن تكون الروابط مؤقتة/موقّعة غير منتهية. تشغيل m3u8 يعتمد على دعم HLS الأصلي في المتصفح.
- رابط ترجمة اختياري عبر `&sub=` (vtt/srt) يحتاج CORS أيضًا.

## حدود عامة
- **الأصوات:** تعتمد على أصوات النظام المثبتة في Quest؛ قد لا يتوفر صوت عربي (يظهر تنبيه) — راجع إعدادات النظام/اللغة. لا يوجد TTS سحابي مدمج (أصوات النظام فقط)؛ اختيار «الصوت الأنثوي» يتم بمطابقة أسماء الأصوات المعروفة.
- قد يتطلب المتصفح لمسة/نقرة أولى قبل السماح بالنطق.
- كشف اللغة بسيط (عدد الحروف العربية مقابل اللاتينية).
- قد تمنع سياسة CSP لبعض المواقع تحميل Tesseract أو مترجم Google عبر الـ Bookmarklet.
